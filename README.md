# Coffee Sales Analysis & Interactive Dashboard

An Excel-based data analytics project focused on exploring coffee sales performance, customer behavior, and sales trends through an interactive dashboard.

## Project Overview

This project analyzes coffee sales data by combining order, customer, and product information to examine sales performance across different time periods, coffee types, countries, and customers.

The project uses Microsoft Excel to prepare the data, perform analysis, and build an interactive dashboard for exploring sales patterns.

## Tools & Skills

- Microsoft Excel
- XLOOKUP & INDEX-MATCH
- Data Cleaning & Preparation
- PivotTables & PivotCharts
- Interactive Dashboard & Data Visualization

## Project Process

1. **Data Integration:** Combined order, customer, and product information using XLOOKUP and INDEX-MATCH.
2. **Data Preparation:** Standardized product categories, formatted data, calculated sales values, and checked for duplicates.
3. **Data Analysis:** Used PivotTables and PivotCharts to explore sales trends, sales by country, and top customers.
4. **Dashboard Development:** Created an interactive dashboard with timelines and slicers to filter data by roast type, product size, and loyalty card status.

## Key Findings

- Sales Trends: Coffee sales fluctuated across different time periods from 2019 to 2022, with varying patterns across roast types.
- Sales by Country: The United States recorded the highest sales among the three countries shown in the dashboard.
- Top Customers: Allis Willmore ranked as the top customer by sales among the five customers displayed.

## Dashboard Features
- Explore sales trends over time using an interactive timeline.
- Compare sales performance across countries.
- Identify the top five customers by sales.
- Filter visualizations by roast type, coffee size, and loyalty card status.
